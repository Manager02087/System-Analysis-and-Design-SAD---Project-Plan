# Week 2: Business Process Modeling (BPM) - PharmaFlow

## 1. Goal
The objective of this week is to visualize how the pharmacy's core business processes work and how the system automates these tasks.

## 2. Core Process: Medicine Sales Flow
This process describes the interaction between the Customer, Pharmacist, and the PharmaFlow System during a sale.

### Process Steps:
1. **Inquiry:** Customer requests a specific medicine.
2. **System Search:** Pharmacist searches for the medicine in the system.
3. **Availability Check:**
   - If **In Stock**: Proceed to checkout.
   - If **Out of Stock**: Suggest alternative or inform the customer.
4. **Validation:** System checks the expiration date of the batch.
5. **Transaction:** Customer pays via Cash or Card.
6. **Auto-Update:** System decrements the stock count and logs the transaction.
7. **Receipt:** System prints/generates a digital receipt.
